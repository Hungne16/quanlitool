# Auto-Push to GitHub

## Workflow Constraint
After successfully completing any coding task, modifying files, or fixing bugs, you MUST automatically:
1. Stage the changes using `git add .`
2. Commit the changes using `git commit -m "<descriptive message>"`
3. Push the changes to the remote repository using `git push`

Do this proactively without waiting for the user to ask. Ensure all tests and verification are complete before pushing.
